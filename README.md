# CS320

How can I ensure that my code, program, or software is functional and secure?

functionality I believes comes form holding yourself as a developer responsible. Testing for code I think should happen at almost every step of the process and this helps to keep your code neat. Code thats easy to read and follow for the next developer coming in to check/debug your base will go a long way
in making sure that as a developer your work is functional. Keeping your programs secure starts with envisioning security from the onset. I'll admit I did not test for security in this class- but it was definitely on my mind! Security for me is a bit of a special intrest and so in the future I would
like to incorporate it into the skeleton of a project. I know I would start with running my program through a dependency checker first and foremost. Specifically we learned about the **OWASP Dependency-Check** utility in another class and I think that would be a great place to start. 

How do I interpret user needs and incorporate them into a program?

I like to think in terms of problem solving when it comes to a user's needs. When I write code for myself I am often solving a problem or making an interaction with technology smoother. Working with clients is the same thing. I put myself in the client's shoes and imagine what I would want if I were writing this
application for myself. Obviously in the real world there are budgets and time constriants, but I think starting from a place of putting yourself in the clients shoes helps out a lot! Second I think it's extremely important to have a face to face meeting with the client to really assertain what they are looking
for from the applicaion. Ideal this meeting would happen over Zoom or similar service and be recorded so it could act a document to reference during development. This serves 2 purpose, 1. it lets new developers come into the project with a good idea of what the client wants from the clients own mouth. 2. It might tell us what is more or less important to the client- facial expression and tone can show us what the client might be excited about the most. It could also show us places where the client ins't as concerned- this could be used to help us manage our time effectively ensuring we are working on what the client really wants.

How do I approach designing software?

Like i mentioned above- software design I think is all about problem solving. When i write for myself I start with an issue that I am having and google away from there. Generally when it comes to an issue with technology- chances are you are not the first person to experience this. 
I rely on the community usually to guide me to a starting point. I think this communal aspect of software design/development is one of the best aspects of the pursuit. Developers will work for hundreds of hours on open sourced image editing software simply so people who don't own photoshop can get some of the same experience. This is my second most important element of software design- it should work to make whatever your fellow user or developer is doing easier! Software was created to help make our lives easier.
